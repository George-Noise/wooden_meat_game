# Changelog

## 1.3.0 - Unreleased

- Добавлен справочник публичного API с назначением, сигнатурами, параметрами и ограничениями, общие правила композиции и полные рецепты модулей. Полнота карточек, ссылки и выполнение рецептов проверяются сборщиком документации. Дополнены аннотации is_over и Tooltip, исправлен тип ключей палитры.

- Разделены инструкции для фоновых картинок и nine-patch: описаны пути текстур, атласы, preload, режимы fit и слой K.Image внутри Box. Добавлен пример cover в F12. Передача fit в K.nine_patch вызывает понятную ошибку; ошибки загрузки и размеров фона содержат имя ресурса и подсказки.

- Пак поставляет декларации TypeScript для VCTS: ядро, Kompot UI и совместимые прямые импорты прокрутки и блокировки инвентаря. Типы генерируются из LuaLS, сохраняют self, LuaMultiReturn, обобщённые состояния и новые API 1.3.0.

- Обновлены типы LuaLS для API 1.3.0 и настроек Kompot UI. В `K.preview` добавлено явное включение `keyboard_navigation`; поведение навигации совпадает с игровым интерфейсом.

- Kompot UI поддерживает оформление поверхностей через `surfaces`: плоский фон, собственные текстуры, формы, рамки, состояния и композицию фона без замены поведения компонентов. Добавлен пример смены оформления в F12; формы применяются и к текстурным поверхностям.

- Добавлен `UI.Select`: управляемый выбор из списка, недоступные варианты, ошибка и режим чтения, прокрутка и клавиатурная навигация.
- Общий обход через Tab включается опцией `keyboard_navigation = true`; по умолчанию обычные кнопки HUD не получают фокус и не перехватывают Tab. Локальное управление полями и списками сохраняется. В F12 навигация включена явно.
- При включённой навигации Tab прокручивает к элементам за пределами видимой области; нативные текстовые поля включены в общий порядок фокуса. Недоступное поле `enabled = false` не принимает ввод.
- Escape запрашивает закрытие верхнего меню или модального окна. Закрытие возвращает фокус прежнему доступному элементу; меню поддерживает стрелки вверх/вниз и Home/End. Рамка фокуса появляется при работе с клавиатурой и использует цвет темы.
- В `UI.Lua` работают стрелки вверх/вниз, Home/End и PageUp/PageDown для прокрутки. Галерея F12 запоминает высоту кода в сессии; у ручки изменения размера появилась подсказка.

- Добавлено общее состояние перехода: `K.transition_state`, `K.new_transition_state` и `K.transition`. Числа и векторы анимируются вместе; `current_state`, `target_state`, `is_idle` и `completion` позволяют выполнять эффекты после завершения всей группы и применения кадра.
- `Window` и `Dialog` принимают `visible_state`, а `Menu` - `expanded_state` для наблюдения за встроенными анимациями через тот же механизм переходов.
- `Dialog` передаёт `on_close` окну; запросы отмены по умолчанию используют его при отсутствии `on_dismiss`. Исправлены аннотации `dismiss`; прежний `cancel` поддерживается как алиас.
- Исправлен светлый ореол яркого фона под скруглённой рамкой: покрытие заливки согласовано со сглаживанием и прозрачностью рамки. Исправление действует также для разных радиусов углов, срезанных углов и экспорта превью.
- Исправлена обрезка последних строк в `UI.Lua`: прокрутка учитывает отступы поля и оставляет под последней строкой запас в одну строку без изменения копируемого текста. `scroll_past_end = false` отключает дополнительное пространство.
- В галерее F12 поле кода подстраивается под длину примера с запасом в одну строку; максимальная исходная высота увеличена с 20 до 40 строк с ограничением по экрану. Высоту можно менять нижней ручкой или стрелками вверх/вниз при её фокусе.
- Исправлена передача колеса от нативного поля к прокручиваемому родителю: проверяется существование элемента, а не результат валидации текста.
- Исправлена подмена и исчезновение масштабированных блоков HUD при изменении соседних элементов: бэкенд сохраняет готовые слои с одинаковым рисунком и геометрией при смене их путей.
- Исправлены коллизии GUI-ID при повторном использовании промежуточных кадров до завершения отложенного удаления элементов движком.

## 1.2.2

- Исправлена потеря нажатия и фокуса при изменении оформления кнопки. Изменение отступов больше не передаёт клик соседнему обработчику.
- Полоса прокрутки обновляется при изменении размеров содержимого, в том числе при первом показе.
- Добавлен параметр `K.mount({lock_inventory = false})`: Kompot не блокирует открытие инвентаря по Tab, даже при наведении и фокусе.
- При уничтожении контейнера Kompot или его XML-документа приложение автоматически освобождает ресурсы и завершает эффекты. Скрытые макеты продолжают хранить состояние.

## 1.2.1

- Исправлены чёрные артефакты и повреждение прозрачности при анимации вложенных повёрнутых элементов в VoxelCore.
- Добавлено сглаживание наклонных поворотов слоёв и `Canvas:image` с корректным смешиванием прозрачных краёв.
- Оптимизирована программная растеризация поворотов через обработку RGBA-буферов.
- Добавлены проверки вложенных вращений, сглаживания и смешивания прозрачности.
