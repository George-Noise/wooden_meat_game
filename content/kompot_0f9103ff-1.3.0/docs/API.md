## Как выбрать API

| Задача | Выбор | Что не выполняется автоматически |
|---|---|---|
| Кнопки и поля фирменного Kompot UI | `UI.*` | Не подменяют игровой код |
| Экран для разных дизайн-систем | `K.ui()` внутри темы с контрактом | Базовая тема ядра не содержит готовый UI |
| Собственная раскладка | `Box/Row/Column/FlowRow`, затем `Layout` при необходимости | FlowRow не виртуализует набор |
| Обычная прокрутка | `scroll_state` и scroll-модификатор | Не создаёт конечную высоту и не уменьшает число детей |
| Тысячи записей | `LazyColumn/Row/Grid` и `lazy_state` | Не изменяет модель и не придумывает устойчивые ID |
| Состояние пока экран существует | `state` | Не переживает удаление области |
| Модель между открытиями | `new_state` у владельца | Не освобождает внешние ресурсы |
| Внешнее нереактивное значение | `poll` | `remember` не опрашивает источник |
| Действие после применения | `effect` с ключами | Это не обработчик клика и не таймер сам по себе |
| Один плавный параметр | `animate` | Не даёт событие окончания группы |
| Действие после нескольких анимаций | `transition_state` + `transition` + `effect` по completion | Начальное is_idle не является завершённым переходом |
| Фоновая иллюстрация без искажения | `Image` с cover внутри Box | Nine-patch не поддерживает fit |
| Рамка с неизменной толщиной углов | `nine_patch` + `background_image` | Не сохраняет пропорции всей иллюстрации |
| Управляемый текст без оформления | `BasicTextField` со state/editor_state | Нативная undo-история не является частью State |
| Оформленное поле с подписью | `UI.TextField` | Валидация и сохранение принадлежат владельцу |
| Число из диапазона | `Slider` или `Stepper` | Stepper не вычисляет шаг и границы |
| Выбор по значению | `Select` или `Choice` | selected должен обновить владелец |
| Выбор по индексу | `Tabs` или `Segmented` | Само содержимое страницы не переключается |
| Произвольное окно | `Window` | Запрос закрытия не меняет видимость модели |
| Подтверждение по центру | `Dialog` | confirm не закрывает диалог автоматически |
| Игровая ячейка с переносом | `ItemSlot/InventoryGrid` | Предметы переносит игровая модель после проверки |
| Картинка миниатюры | `UI.Preview` | Это не `K.preview` для редактора |

## Как читать карточку

Каждая публичная функция и метод имеют назначение, сигнатуру, контракт,
ссылки на типы и руководство. Там, где поведение зависит от исходных значений,
они указаны отдельно и сверены с реализацией. `?` означает возможность не
передавать значение; оно не означает `false`, `0` или универсальный default.

Типы props наследуют общие структуры для аннотаций. Реальная обёртка может
передавать только часть полей: например, геометрию Dialog настраивают через
Window. Такие ограничения явно описаны в карточках и общих правилах.
Дополнительное поле Lua-таблицы не получает смысл только от своего имени.

## Поддержание справочника

Назначение и ограничения находятся в `tools/api_reference_data.py`,
сигнатуры и структуры - в `annotations/`. `tools/build_api_reference.py`
собирает API_CORE, API_UI и API_TYPES. Новая публичная функция без описания,
удалённая функция с оставшейся карточкой и неизвестное поле структуры
приводят к ошибке генерации вместо незаметного пробела в справочнике.

```sh
python3 tools/build_api_reference.py
python3 tools/build_api_reference.py --check
python3 tools/build_ai_guide.py
```

Готовые Markdown-файлы входят в релизный архив и читаются без инструментов
разработки. Встроенный F12 дополнительно показывает живые примеры из кода пака.
